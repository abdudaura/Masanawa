# Source Map — AIRI

Pinned: `85d90ab067ac4625875d5808364bd03bf324645e`.

Status: Phase 0A initial map.

AIRI is a digital-life/virtual-character platform built around bringing persistent AI characters into web/desktop/device contexts.

Evaluate:
- character embodiment across browser/desktop/mobile-like surfaces;
- Live2D/VRM/visual character runtime;
- realtime voice/personality experience;
- local/cloud provider abstraction;
- gaming/application interaction and environment awareness;
- desktop shell/state synchronization;
- character card/persona concepts;
- client architecture for a continuously present digital being.

Likely role: primary external donor for embodied/digital-life client architecture, secondary for perception/proactivity.

Caution: Masanawa identity, memory, world and tasks remain canonical server/domain concepts rather than AIRI client state.
