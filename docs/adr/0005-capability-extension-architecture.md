# ADR-0005: Skills, Tools and Plugins

Status: accepted
Date: 2026-10-01

## Decision

Masanawa's capability model is:

Capability -> Tool -> Skill -> Character Expertise.

OpenJarvis supplies the structural skill/execution pattern.
ChatWithStars supplies governance/certification/readiness.
N.E.K.O supplies plugin packaging/process-lifecycle ideas.

A plugin may package/register canonical components but cannot create a parallel memory, identity, agent or workflow runtime.

External skills/plugins are untrusted until parsed, provenance-recorded, capability-checked, sandboxed as applicable, tested and certified.
