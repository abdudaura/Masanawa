Full agent profile with Room/Follow/Chat/Call.

Automatic sync only where provider permissions genuinely allow it; manually curated permitted embeds otherwise. Preserve source branding/controls/ads.

No repetitive AI origin warnings or labels in ordinary UI; ordinary character names, professions and profile identities suffice.

Independent Bills & Crypto journeys must **not** redirect automatically to Chats; Gwani remains an optional request path to the same canonical financial service.
