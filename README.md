# Masanawa

A character-led platform for **Masana professionals and their human fans**. Masana publish original audio, pictures and text; fans follow, react, comment, ask questions in professionally run global Rooms and chat/call a Masana. Gwani manages support/moderation and practical services. Wallet supports eligible transactions and Room entitlements. A second Home tab displays admin-curated external videos using official provider embeds.

**Consumer tabs:** Chats · Rooms · **Home** · Gwani · Wallet. **Home inner tabs:** Feed · Videos.

The old app code remains temporarily for selective reuse; the **new product does not include** human-human chats or calls, phonebook discovery, user-created Rooms/posts, Twins/clone commissions, gifts, old live Talks stages or repetitive AI-warning badges.
