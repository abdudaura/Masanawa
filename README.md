# Masanawa

Masanawa is the greenfield canonical platform for persistent AI characters, agents, digital humans, skills, tools, world state, multimodal presence, useful work, social activity, commerce and media production.

This repository is intentionally **not** a copy of ChatWithStars, OpenJarvis, N.E.K.O or CyberVerse. It is a clean implementation of the validated union of their capabilities.

## Start here

Every new implementation session MUST read, in order:

1. `CONTINUE-HERE.md`

## Governing rule

> Masanawa is not a merger of repositories. It is a clean implementation of the union of their validated capabilities. Source projects are specifications and donors, never runtime boundaries.

## Source systems

- Baatiku/chatwithstars — domain truth: persistent Stars, fan isolation, world/life state, JEV, workflows, commerce, social, studio, Ops.
- open-jarvis/OpenJarvis — primary architecture donor for agents, skills, tools, events/traces, local/cloud intelligence and learning.
- Project-N-E-K-O/N.E.K.O — primary architecture donor for companion cognition, memory taxonomy, proactivity, perception, embodiment and plugin experience.
- Lynpoint/CyberVerse — primary architecture donor for realtime digital-human presence, WebRTC, interruption and foreground/background interaction.

Exact pinned source revisions are recorded in `docs/migration/SOURCE-LOCK.md`.
